🎮 Dealers.sh — TUI-клиент. Гайд для новичка

Это терминальная программа, которая рулит всеми твоими NFT-дилерами Dealers.sh с одного экрана: покупка/продажа, PVP, рейды, побег из тюрьмы, арбитраж между зонами. Всё в чейне Abstract.

━━━━━━━━━━━━━━━━━━━━
⚙️ ЧАСТЬ 1. УСТАНОВКА
━━━━━━━━━━━━━━━━━━━━

▪️ Шаг 1. Получить программу
• Если тебе скинули готовый файл dealers-tui.exe — клади его в отдельную папку и переходи к Шагу 2.
• Если собираешь сам — поставь Go 1.26+ (https://go.dev/dl/), открой папку проекта в терминале и собери:
```
go build -o dealers-tui.exe ./cmd/dealers-tui
```

▪️ Шаг 2. Создать config.json
Скопируй пример configs/config.example.json рядом с программой под именем config.json и открой в блокноте. Заполни:
```
{
  "active_network": "mainnet",
  "wallet": {
    "address": "0xАДРЕС_КОШЕЛЬКА_ГДЕ_ЛЕЖАТ_ДИЛЕРЫ",
    "source": "keyring",
    "keyring_service": "dealers-tui",
    "keyring_user": "mainnet-owner"
  },
  "min_eth_runway_wei": "5000000000000000"
}
```
❗️ Важно про кошелёк:
• address — это адрес, на котором лежат твои NFT-дилеры (твой AGW / игровой кошелёк). Именно его видно в игре.
• Приватный ключ — от кошелька-ПОДПИСАНТА (у AGW это отдельный EOA). Если играешь обычным кошельком (не AGW), то это просто ключ от того же адреса.

▪️ Шаг 3. Спрятать приватный ключ
Ключ НЕ пишется в файл — он кладётся в защищённое хранилище системы. Выполни:
```
dealers-tui set-key dealers-tui mainnet-owner
```
Программа попросит вставить приватный ключ — вставь и нажми Enter. Один раз.

▪️ Шаг 4. Запуск
```
dealers-tui
```
Увидишь таблицу своих дилеров. Всё готово 🎉

━━━━━━━━━━━━━━━━━━━━
🖥 ЧАСТЬ 2. ГЛАВНЫЙ ЭКРАН (флот)
━━━━━━━━━━━━━━━━━━━━

Таблица со всеми дилерами. Колонки:
• REP — репутация (главный прогресс, открывает ранги и PVP)
• PvE# / PvP# — твоя позиция в лидербордах (PvE по репе, PvP по infamy)
• Heat — розыск копов 0–5 (чем выше, тем выше шанс ареста)
• Cash — игровой $CASH
• Area — текущая зона (Manhattan, Amsterdam…)
• Energy — дневной лимит действий (⚡). Кончился — не поторгуешь
• Infamy — слава в PVP
• Status — IDLE / JAILED / SAFEHOUSE

Клавиши:
• ↑/↓ — двигаться по списку
• Enter — открыть дилера
• m — рынок и арбитраж 💰
• A — автопилот (вкл/выкл, тратит деньги/энергию — по умолчанию ВЫКЛ)
• r — обновить · q — выход

💡 Русская раскладка работает — можно жать те же клавиши с русской раскладкой.

━━━━━━━━━━━━━━━━━━━━
🕹 ЧАСТЬ 3. ДЕЙСТВИЯ (карточка дилера, Enter)
━━━━━━━━━━━━━━━━━━━━

• b — Купить наркотик
• s — Продать
• p — PVP: напасть на другого дилера
• t — Travel: переехать в другую зону
• h — Heist: запустить рейд
• c — Снять heat (постер — бесплатно, тратит 1 энергию, ~50%)
• a — Восстановить энергию (стоит ETH)
• r — обновить · esc — назад

В форме покупки/продажи: ↑/↓ — выбрать товар (показывает цену и твой остаток), печатаешь количество, Enter — отправить. Программа сама подскажет максимум (max N).

⚠️ Купля/продажа — это ставка, не гарантия! Исход: 50% ничья (обычная сделка), 25% выигрыш (бонус), 25% проигрыш (теряешь ставку). За риск капает репутация.

━━━━━━━━━━━━━━━━━━━━
🧠 ЧАСТЬ 4. ЧТО НАДО ПОНИМАТЬ НОВИЧКУ
━━━━━━━━━━━━━━━━━━━━

1️⃣ Energy (⚡) ≠ Heat.
Energy — это твоя «энергия» на действия (дневной лимит). Кончилась — жми a (сброс за ETH) или жди 00:00 UTC.
Heat — уровень розыска. Высокий heat = шанс ареста. Снимается через c (бесплатно) или заодно при выходе под залог.

2️⃣ Каждое действие тратит 1 энергию (независимо от объёма). Поэтому торгуй большими партиями за раз.

3️⃣ Лимит на сделку. У низких рангов можно купить/продать немного за раз (упираешься в «stake cap»). Растёт с рангом — качай REP.

4️⃣ Если арестовали (JAILED):
• k — Breakout: побег БЕСПЛАТНО, ~50%, 1 попытка в сутки
• l — Bail: залог за ETH, мгновенно и сбрасывает heat
Сначала пробуй k (бесплатно), не повезло — l или ждёшь завтра.

━━━━━━━━━━━━━━━━━━━━
💰 ЧАСТЬ 5. КАК ПОДНЯТЬ БАБЛА (арбитраж)
━━━━━━━━━━━━━━━━━━━━

Жми m на главном экране — там таблица «где купить дёшево → где продать дорого»:
```
Heroin  buy 90 @Colombia → sell 240 @Dubai  +150/u
Weed    buy 1  @Manhattan → sell 2 @Amsterdam +1/u
```
Схема заработка:
1. Смотришь маршрут на рынке (m)
2. t — едешь в зону покупки
3. b — покупаешь БОЛЬШУЮ партию
4. t — едешь в зону продажи
5. s — продаёшь

📌 Нюансы: travel стоит ETH (кроме Manhattan↔Amsterdam — бесплатно), дорогие маршруты требуют высокого REP (показано в таблице). Начинай с Manhattan→Amsterdam на Weed, дальше открывай зоны по мере роста репы.
